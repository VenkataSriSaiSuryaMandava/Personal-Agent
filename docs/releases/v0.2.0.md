# Aegis AI v0.2.0

Status: release candidate; publication requires approval.

## Highlights

- Shared Owner and Guest workspace interface.
- Runtime-controlled access policy.
- Reliable authenticated Gemini conversations.
- Configurable local AI usage limits.
- Persistent conversation history.
- Reopen, rename and delete conversations.
- Restore active conversation after browser refresh.
- Explicit local retention controls.
- SQLite schema v4 and verified migration backup.
- Docker Compose private runtime.

## Validation

- 19 CI checks passed on PRs #46 and #47.

- Six navigation regression checks passed.
- Public and private history isolation passed.

## Privacy

Retention is disabled by default.
Public Guest access excludes private data and live AI.
Local database storage is not application-encrypted.
