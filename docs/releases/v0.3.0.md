# v0.3.0 — Functional Personal Workspaces

Release candidate. Production promotion and publication require
explicit approval.

## Highlights

- Nine functional local productivity workspaces.
- Dedicated Jobs application pipeline.
- Local email drafts and calendar views.
- Research, coding and browser record management.
- Manual memory and approval workspaces.
- Workspace summaries and real storage measurements.
- Centralized Gemini-only provider registry.
- Consistent responsive Settings and workspace interfaces.

## Security and persistence

- SQLite schema v6.
- Owner-scoped workspace records.
- Transactional workspace audit events.
- Optimistic revision checks.
- Strict request and payload validation.
- Verified migration backups.
- Separate private Owner and public Guest runtime boundaries.

## Limitations

External account connections are not implemented.
Email drafts are not sent, and calendars do not synchronize.

Saved memories are not automatically attached to AI requests.
Approval records do not authorize external actions.

Gemini is the only implemented model provider. No automatic
fallback or local language model runtime is enabled.

Local storage is not application-encrypted. Autonomous execution,
remote Owner access and OS-level sandboxing remain deferred.
